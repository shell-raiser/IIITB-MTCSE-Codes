Good Index Pairs

Problem Statement
Given two integer arrays A and B, each of length n, count the number of index pairs (i, j) satisfying

    0 <= i < j < n

and

    A[i] < B[j].

A direct examination of all pairs requires quadratic time. Design and implement a more efficient algorithm.

Input
The first line contains an integer n.
The second line contains n integers: A[0], A[1], ..., A[n-1].
The third line contains n integers: B[0], B[1], ..., B[n-1].

Output
Print the number of good pairs.

Constraints
1 <= n < 1000000
-10^15 <= A[i], B[i] <= 10^15

Note
The answer may not fit in a 32-bit signed integer. Use a 64-bit integer type.

Sample Input 1
4
1 5 2 4
3 1 6 5

Sample Output 1
5

Explanation
The good pairs are (0, 2), (1, 2), (0, 3), (1, 3), and (2, 3).

Sample Input 2
3
5 5 5
5 5 5

Sample Output 2
0
